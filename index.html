Distribuição da coluna Entradas

Selecione notas em "Entradas" e envie para a coluna de tratamento correspondente. Por padrão a pessoa é escolhida automaticamente por rodízio entre os operadores ativos daquela coluna, mas você também pode distribuir diretamente para um usuário específico — útil para acompanhar e validar quanto tempo cada pessoa leva para concluir.

Atribuição em massa

Selecione várias notas já em tratamento (Lançamento, Financeiro/CX ou Pendências) e atribua todas de uma vez a um usuário específico — sem precisar trocar o responsável nota por nota.

Importar notas do relatório SIENGE

Selecione o relatório exportado do SIENGE (.xlsx). São importados apenas os registros com o campo "Título/Nota fiscal avulsa" vazio (ainda não escriturados) — eles caem na coluna "Importadas SIENGE" (no Quadro) com os dados padrão já preenchidos (fornecedor, número, valor, emissão), prontos para você completar o que faltar (obra, vencimento, forma de pagamento etc.) usando "Editar".

Cadastrar nota fiscal

A nota é registrada para lançamento via Sede AMETA e cai automaticamente na coluna "Entradas". Você já pode anexar aqui os documentos relacionados (nota, comprovantes etc.).

Vincular usuário

O login (e-mail e senha) é criado no painel do Supabase, em Authentication > Users (peça isso ao responsável técnico). Aqui você só define o papel de acesso e, para supervisor/operador, a coluna de trabalho — use exatamente o mesmo e-mail já criado no Supabase.

Equipe

Redefinição de senha não é feita por aqui: peça para a pessoa usar "Minha conta" (se ela ainda tem acesso) ou redefina pelo painel do Supabase em Authentication > Users.
